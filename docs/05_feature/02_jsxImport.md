# 東証上場銘柄マスタ更新仕様書

## 1. 目的

日本取引所グループ（JPX）が公開している最新の上場銘柄リストを取得し、システム内の銘柄マスタ（`spt_stocks`）の名称やコード等の情報を最新の状態に更新する。

## 2. 準備（データソース）

* **ソース名**: 日本取引所グループ公式統計資料（東証上場銘柄一覧）
* **URL**: [その他統計資料 | 日本取引所グループ](https://www.jpx.co.jp/markets/statistics-equities/misc/01.html)

---

## 3. 更新手順

### ステップ1：最新データのダウンロード

1. 上記URLにアクセスする。
2. 「統計資料」セクションにある**「その他統計資料」**内の**「東証上場銘柄一覧」**（Excelファイル）をクリックしてダウンロードする。

### ステップ2：データの抽出（Excel操作）

1. ダウンロードしたExcelファイルを開く。
2. データが記載されているシートを選択し、全ての列（A列〜J列など、データが存在する範囲全体）を選択する。
3. `Ctrl + C` を押下し、クリップボードにコピーする。

### ステップ3：システムへの取り込み

1. 本システムの**「銘柄マスタ更新ページ」**（または管理画面内の該当URL）にアクセスする。
2. 入力エリア（テキストエリア）に、コピーしたExcelの内容を貼り付ける。
3. 画面上の**「取り込み処理」**ボタンを押下する。

---

## 4. 処理仕様（内部ロジック）

取り込み処理が実行されると、システム内部では以下の処理が行われる。

| 処理ステップ | 内容 |
| --- | --- |
| **パース処理** | 貼り付けられたタブ区切り（TSV形式）のテキストを解析し、コード・銘柄名・市場区分等を抽出する。 |
| **バリデーション** | 銘柄コードが4桁の数字（または英字混じり）であることを確認する。 |
| **DB更新 (UPSERT)** | 銘柄コードをキーとして、`spt_stocks` テーブルの既存情報を更新、存在しない場合は新規登録を行う。 更新対象は「spt_stocks」「jpx_company_master」とする|

---

## 5. 注意事項

* **データ構造の変化**: JPX側のExcelの列構成が変更された場合、ステップ3の「パース処理」に失敗する可能性があるため、定期的なメンテナンスが必要。
* **実行タイミング**: 銘柄の新規上場や市場変更は頻繁に行われるため、月1回程度の更新を推奨。

### spt_stocks

個々の銘柄（企業）の基本情報

| カラム名     | 型        | 補足|
| ------------ | --------- | --------------------------------- | 
| code         | text      | 主キー。銘柄コード（例: 7203）。YahooFinanceAPIなどで一意に識別されるコードで、NOT NULL制約で必須項目とします。 | 
| name         | text      | 銘柄名/会社名（例: トヨタ自動車）。NOT NULL制約で必須項目とします。 | 
| market       | text      | 上場市場（例: 東証プライム, ナスダック など）。任意項目。| 
| industry     | text      | 業種（例: 自動車, 電気機器 など）。任意項目。        | 
| tradable     | boolean   | 取引可能フラグ。現在取引されている銘柄かどうかを示す（任意、デフォルトTRUEなど）。   | 
| listing_date | date      | 上場日。任意項目。 | 
| created_at   | timestamp | レコードが挿入された日時。now()で自動的にタイムスタンプが設定されます。| 
| updated_at   | timestamp | レコードが最終更新された日時。now()で自動更新されるように設定することが一般的です。 |
