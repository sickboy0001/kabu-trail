# 01_ストックバスケット機能 (Stock Basket)

## 1. 目的

ユーザー独自の視点や投資テーマに基づき、複数の銘柄を詰め合わせた「バスケット（カゴ）」を構築・管理することを目的とする。
実際の保有資産（リアルポートフォリオ）とは切り離し、理想の組み合わせや、特定の市場セクターの動向を「セット単位」で観察するための機能である。

## 2. ユーザーストーリー

* ユーザーは、「2026年本命」「半導体セット」「高配当バスケット」など、自由な名前で複数のバスケットを作成できる。
* ユーザーは、作成したバスケットを切り替えることで、異なる投資テーマの現在状況を瞬時に把握できる。
* ユーザーは、個別の銘柄の動きだけでなく、バスケット全体の騰落率を見て、自分の仮説が正しいかを評価できる。

## 3. 主要機能 (機能要件)

### 3.1 バスケット管理

* **バスケットの編成・編集・削除**: 複数の銘柄を1つの「カゴ」としてまとめて管理する。
* **テーマ（バスケット名）設定**: 「割安株」「景気敏感」など、戦略がわかる名前を付与できる。

### 3.2 銘柄（ストック）管理

* **バスケットへの投入**: 銘柄コードや企業名検索から、対象のバスケットへ素早く銘柄を追加できる。
* **銘柄の整理**: バスケット内での並び替えや、別のバスケットへのコピー・移動ができる。

### 3.3 モニタリング・分析表示

* **バスケット一覧ビュー**: 最新価格、前日比、騰落を銘柄ごとに表示する。
* **バスケット・スタッツ (将来機能)**: バスケット全体の平均騰落率や、日経平均等との相関を表示し、テーマごとの市場の強弱を可視化する。

## 4. データ構造案 (メモ)

### StockBaskets (stock_baskets)
ユーザーが作成したバスケット（カゴ）の基本情報。

| カラム名 | 型 | 説明 |
| --- | --- | --- |
| id | bigint | PK |
| user_id | uuid | 所有ユーザーID (FK: auth.users) |
| name | text | バスケット名 |
| description | text | 説明・メモ |
| sort_order | integer | 表示順序 |
| created_at | timestamp | 作成日時 |
| updated_at | timestamp | 更新日時 |

### StockBasketItems (stock_basket_items)
バスケットに含まれる銘柄のリスト。

| カラム名 | 型 | 説明 |
| --- | --- | --- |
| id | bigint | PK |
| stock_basket_id | bigint | 所属バスケットID (FK: stock_baskets) |
| stock_code | text | 銘柄コード (FK: spt_stocks) |
| sort_order | integer | 表示順序 |
| added_at | timestamp | 追加日時 |

## 5. UI/UX イメージ

* **「市場監視」メニュー**: 保有資産（Assets）とは別のメインメニューとして配置。
* **バスケット・タブ**: 画面上部のタブやサイドバーで複数のバスケットを切り替え、ドラッグ＆ドロップで銘柄を入れ替えられる直感的な操作感を目指す。

## 6. DB設計 (SQL定義)

Supabase (PostgreSQL) 用のテーブル定義とRLSポリシー。

```sql
-- 更新日時自動更新用の関数
create or replace function handle_updated_at() returns trigger as $$
begin
  new.updated_at = now();
  return new;
end;
$$ language plpgsql;

-- 1. StockBaskets テーブル
create table stock_baskets (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users not null,
  name text not null,
  description text,
  sort_order integer default 0,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 更新日時トリガー
create trigger on_update_stock_baskets
  before update on stock_baskets
  for each row execute procedure handle_updated_at();

-- RLS無効化と権限付与
ALTER TABLE stock_baskets DISABLE ROW LEVEL SECURITY;
GRANT ALL ON TABLE stock_baskets TO authenticated;
GRANT SELECT,UPDATE,INSERT,DELETE ON TABLE stock_baskets TO anon;


-- 2. StockBasketItems テーブル
create table stock_basket_items (
  id bigint generated by default as identity primary key,
  stock_basket_id bigint references stock_baskets(id) on delete cascade not null,
  stock_code text references spt_stocks(code) not null,
  sort_order integer default 0,
  added_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- RLS無効化と権限付与
ALTER TABLE stock_basket_items DISABLE ROW LEVEL SECURITY;
GRANT ALL ON TABLE stock_basket_items TO authenticated;
GRANT SELECT,UPDATE,INSERT,DELETE ON TABLE stock_basket_items TO anon;
```
